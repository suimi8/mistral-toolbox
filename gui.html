API key 保存后立即热更新生效（无需重启反代）：/v1/* 请求必须带 Authorization: Bearer <key> 或 x-api-key 头，未带/错误返回 401；不设置 key 时 /v1 不校验。
客户端形态：反代与 Vibe 桌面端（le-chat-desktop）发的是同一套 chat.mistral.ai 对话接口（逆向实证：桌面端 UI 就是 le-chat-web 源码，主进程只是转发层）； 勾选「桌面端形态」后 UA 会带上桌面端同款标记 LeChat-Desktop/1.6.0 (win32; production; x86_64)，保存立即热生效（client_profile.txt）。
多账号池从 accounts.json 读取：Pro 优先轮转，Free 兜底，429 自动冷却切换；批量注册 / 一条龙 / 登录 / 体检完成后自动热更新入池，无需重启。
